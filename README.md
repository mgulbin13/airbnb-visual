# Airbnb Visualization Project

## Overview

This project is an examination and visualization of a dataset of Airbnbs in NYC. The goal of this project is to provide insights into where users can stay during their time in NYC, including which neighborhood is the most affordable, highest rated, etc. Another section of the project is creating a nice looking geographical visualization within Tableau.

On a personal level, this project was an opportunity practice my data cleaning and visualization skills, utilizing Tableau and pandas.

## Data Summary

The data for this project was taken from [this dataset from Kaggle](https://www.kaggle.com/datasets/arianazmoudeh/airbnbopendata). The data consisted of 100,000 Airbnbs within the five boroughs of New York City.
